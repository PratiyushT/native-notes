# Native Notes 2.5.0

Compose equations, build flowcharts, and insert note components directly in the editor.

- **Math keyboard:** a larger, rounded keyboard button appears while editing math. Choose any editor corner; bottom buttons stay above the status bar. Open a draggable keyboard beside the equation on desktop, or a full-width keyboard on phones and tablets. All controls stay in the current window. Inline equations, table cells, callouts, and nested lists retain their exact editing positions.
- **Math templates and rendering:** browse 236 keys across 12 categories, search symbols, and move between template fields. The full equation composer has a live preview. Optional bundled math rendering works offline in Live Preview and Reading view.
- **Visual flowcharts:** drag shapes onto a canvas, connect nodes, edit labels, and arrange the chart. Notes retain ordinary Mermaid source, with visual positions stored as comments.
- **Slash insertion menu:** type `/` to browse components and keep typing to filter them. Fuzzy search, keyboard navigation, and touch selection work locally; `/cal` finds callouts.
- **Cleaner editing:** image-alignment metadata stays hidden while editing, and indentation guides no longer appear beside indented text or code.

The illustrated guide and screenshots cover the new tools and settings. Existing preferences are retained, and keyboard position defaults to bottom right. No note migration is required. The minimum Obsidian version remains 1.13.0.

Native macOS and desktop touch-layout fixtures have been checked. Native Windows/Linux and physical iPhone/iPad testing remain outstanding. Copy controls still write only after an explicit click; no telemetry or plugin network requests were added.
