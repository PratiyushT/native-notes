Native Notes' settings and guides now describe its own features directly. Floating outline and code highlighting keep the same behavior and defaults, with clearer descriptions and refreshed settings screenshots.

The intentional clipboard-write advisory for code Copy and profile Copy remains disclosed. Validation includes all 336 automated tests, lint, build, and the full dependency audit.
