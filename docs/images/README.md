# Documentation screenshots

## Settings captures for 2.4.4

`optional-features.png` and `code-settings.png` were captured from Native Notes 2.4.4 running in Obsidian 1.14.5 on macOS on October 23, 2026. Both show the actual settings interface in an isolated scratch vault, using the Notes preset in light mode and fresh-install defaults.

- `optional-features.png` shows the Optional features section through Extra table spacing, including the floating outline and empty-line controls.
- `code-settings.png` shows the whole Code blocks section: built-in and inline highlighting on, line numbers and wrapping off, and frame set to Auto.

The images use application zoom and crop framing only. Both were inspected for legibility and privacy; no personal notes, vault identity, account details, or local paths appear. The capture left saved preferences unchanged.

## Retained appearance captures from 2.2.0

The two retained settings assets were captured from Native Notes 2.2.0 running in Obsidian 1.14.4 on macOS on October 23, 2026. They show retained settings, but are not evidence of a current-version runtime check.

- `appearance-settings.png` and `profile-settings.png` show the actual settings renderer with fresh-install appearance defaults. Each is cropped to its named section; neither shows the retired cloud-folder or recovery controls.

No personal notes, account information, local paths, or recovery history appear in these earlier images. That demonstration changed no stored appearance or recovery preferences and created no additional vault.

All screenshots demonstrate the macOS interface. No actual Windows, Linux, iPhone, or iPad testing is established by these captures.
