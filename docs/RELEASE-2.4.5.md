# Native Notes 2.4.5

This maintenance release updates the distribution process and repairs guide links. Appearance, editor tools, defaults, and settings behavior are unchanged; `main.js` and `styles.css` are identical to 2.4.4.

Development now takes place in a private repository. The public Native Notes repository continues to provide installation files, releases, and user guides, and updates remain available through Obsidian. Copies of previously published source may remain available.

Release publishing verifies the installation files before making a new version available for updates. The minimum supported Obsidian version remains 1.13.0.
