# Native Notes

Apple-inspired design and editor tools for Obsidian.

This distribution snapshot preserves the published Native Notes 0.1.10 runtime files. Install the plugin through Obsidian's Community plugins browser, or download the runtime assets from the [0.1.10 release](https://github.com/PratiyushT/native-notes/releases/tag/0.1.10).

The authoring source and development history are maintained in a separate private repository. This public repository provides installable releases and the [issue tracker](https://github.com/PratiyushT/native-notes/issues).
